# 背诵文件名

## kernel/

| 文件 | 作用 |
|------|------|
| entry.S | 开机第一条指令，关中断、设置栈指针、跳转 start |
| start.c | M 模式初始化，配置时钟中断，跳转 main |
| main.c | S 模式初始化入口，按序初始化所有子系统 |
| kalloc.c | 物理页分配器（链表式空闲页） |
| vm.c | 虚拟内存：页表创建、映射、取消映射、uvmcopy、copyout/copyin |
| vm.h | vm.c 外部接口声明 |
| proc.c | 进程生命周期：allocproc/freeproc/scheduler/wakeup/wait/exit/kill/sleep |
| proc.h | struct proc、struct cpu、struct context 定义 |
| swtch.S | 上下文切换汇编 |
| trap.c | 异常/中断分发：usertrap、kernelvec、timerint |
| trampoline.S | 用户态陷入/返回到内核的跳板 |
| syscall.c | 系统调用表 + syscall() 分发函数 |
| syscall.h | 系统调用号宏定义 |
| bio.c | 块缓存层（buffer cache，LRU 替换） |
| log.c | 日志层，实现崩溃恢复的事务语义 |
| fs.c | inode 管理、路径解析、读写文件 |
| fs.h | 磁盘上的超级块、dinode、目录项结构 |
| file.c | 文件描述符层（file table, open/read/write 分发） |
| file.h | struct file 定义 |
| exec.c | exec 系统调用：加载 ELF 文件 |
| pipe.c | 管道实现 |
| spinlock.c | 自旋锁实现 |
| spinlock.h | struct spinlock 定义 |
| sleeplock.c | 睡眠锁实现（等待 I/O 时释放 CPU） |
| sleeplock.h | struct sleeplock 定义 |
| uart.c | 16550 UART 串口驱动 |
| console.c | 控制台输入输出（包装 uart） |
| plic.c | RISC-V PLIC 中断控制器初始化 + 处理 |
| virtio_disk.c | virtio-blk 磁盘驱动 |
| printf.c | 内核 printf |
| string.c | memcpy/memmove/strlen/strcmp 等 C 库函数 |
| riscv.h | RISC-V 指令/寄存器/CSR 内联汇编宏 |
| memlayout.h | 内核地址空间布局常量 |
| param.h | 参数常量（最大进程数、栈大小等） |
| types.h | uint64/int 等类型定义 |
| defs.h | 所有函数的前向声明 |
| kernel.ld | 内核链接脚本 |

## user/

| 文件 | 作用 |
|------|------|
| init.c | 第一个用户进程，fork 启动 shell |
| sh.c | shell：解析命令、管道、重定向、后台执行 |
| cat.c | cat 命令 |
| echo.c | echo 命令 |
| grep.c | grep 命令 |
| ls.c | ls 命令 |
| mkdir.c | mkdir 命令 |
| rm.c | rm 命令 |
| ln.c | ln 命令 |
| wc.c | wc 命令 |
| kill.c | kill 命令 |
| forktest.c | fork 边界测试（耗尽进程表） |
| stressfs.c | 文件系统压力测试 |
| usertests.c | 综合性系统调用测试 |
| grind.c | 综合压力测试（多次 fork/exec） |
| zombie.c | 测试僵尸进程 |
| logstress.c | 日志压力测试 |
| forphan.c | 孤儿进程测试 |
| dorphan.c | 孤儿进程测试配套 |
| ulib.c | 用户态 C 库（strcpy/printf/malloc 等） |
| umalloc.c | 用户态 malloc/free |
| printf.c | 用户态 printf/fprintf |
| usys.pl | Perl 脚本，生成 usys.S（系统调用汇编存根） |
| usys.S | 系统调用汇编存根（由 usys.pl 生成） |
| user.h | 用户态函数的头文件声明 |
| user.ld | 用户程序链接脚本 |
